# Contributing

Thanks for helping out! A few rules keep `main` healthy:

1. **Fork** the repository and work on a branch in your fork.
2. Keep each pull request focused on one change, and describe *what* and *why*.
3. Make sure CI passes. Pull requests from first-time contributors need a
   maintainer to approve the CI run before it starts.
4. Every pull request is reviewed by the maintainer and merged with
   **squash merge**. Direct pushes and force pushes to `main` are blocked.
5. Never commit secrets (API keys, tokens, passwords). Secret scanning with
   push protection is enabled and will reject such pushes.

Security issues: see [SECURITY.md](SECURITY.md) — please report them privately.
